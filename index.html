(Projet phare) en cours

Les agents IA ont désormais les clés. Je vérifie qu'elles n'ouvrent pas tout.

Scanner de sécurité pour serveurs MCP

Le MCP (Model Context Protocol), c'est la prise qui permet à un agent IA d'utiliser des outils : lire des fichiers, interroger une base, lancer une commande. Si cette prise est mal câblée, l'agent, et toute personne qui arrive à le manipuler, peut aller bien plus loin que prévu. Je développe en Python un outil qui trouve ces failles avant un attaquant.

Ce qu'il traque

Mauvaises configurations

Secrets exposés, authentification absente, réglages dangereux par défaut.

Permissions excessives

Un outil censé lire un dossier qui peut lire tout le disque.

Contrôle d'accès

Un appel qui atteint des données ou des actions qui ne lui sont pas destinées.

Comment, dans l'ordre

  1. 1Audit statiqueLecture du code et de la configuration : outils déclarés, permissions, authentification.
  2. 2Tests dynamiquesLe serveur tourne dans un conteneur Docker isolé, et le scanner appelle réellement ses outils.
  3. 3ClassementChaque constat est rangé dans une catégorie de l'OWASP MCP Top 10.
  4. 4RapportUne preuve reproductible et un correctif pour chaque faille.

mcp-scan · serveur filesystem · test #07
